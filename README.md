# Баялаг — гостевой дом в Аршане

Одностраничный сайт для бронирования гостевого дома в пос. Аршан (Тункинская долина, Бурятия).
Статический: `index.html` + `assets/`. Сборка не нужна — можно выложить на GitHub Pages, Vercel, Netlify или любой хостинг.

## Перед запуском

Откройте `assets/script.js` и заполните контакты в `CONFIG` (телефон, WhatsApp, Telegram, почта).
Форма бронирования собирает заявку и предлагает отправить её хозяину через эти каналы.
